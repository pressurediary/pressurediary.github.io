# Pressure Diary · Tansiyon Takip — website

Public website of the Pressure Diary / Tansiyon Takip app, served by GitHub Pages
from the `pressurediary` organization.

| Page | URL |
|---|---|
| App page | https://pressurediary.github.io/ |
| Privacy policy (TR + EN) | https://pressurediary.github.io/privacy.html |
| app-ads.txt (AdMob) | https://pressurediary.github.io/app-ads.txt |

The repository must be named `pressurediary.github.io` (organization name + `.github.io`)
so the site is served from the domain root: AdMob only looks for `app-ads.txt` at the root
of the developer website listed in the stores.
